# Ana Hristova — Engineering & Product Leadership Portfolio

A responsive, static website with a balanced consulting and executive-leadership focus. All content is included in the extracted folder. No framework, installation, or build step is required.

## Preview
Open `index.html` in a modern browser, or run `python -m http.server 8000` in the extracted folder and visit `http://localhost:8000`.

## Publishing
- Netlify: deploy the folder or connect a Git repository.
- GitHub Pages: publish the project files from the root directory.
- Vercel: import the repository as a static project without a build command.

## Files
- `index.html` — site structure and content
- `styles.css` — the consolidated, responsive LinkedIn-inspired blue design
- `script.js` — mobile navigation, case-study expand/collapse, and testimonials carousel navigation
- `ana-hristova.jpg` — Ana’s supplied profile photograph
